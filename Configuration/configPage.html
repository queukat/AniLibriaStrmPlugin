Авторизация AniLiberty API

Есть два варианта: Login/Password (получить токен сразу) и OTP (двухшаговый, устройство + код). После успешного входа токен сохраняется в конфигурацию (AniLibertyToken).

1. Вход по логину и паролю
Будет вызван POST /accounts/users/auth/login. Ответ должен содержать поле token. Токен сразу сохранится; перезапуск Jellyfin не требуется.
2. OTP (устройство + код)
Поток:
  1. Start OTP – генерирует DeviceId (если пуст) и получает otp.
  2. Вы вводите / подтверждаете код на стороне AniLiberty (если требуется).
  3. Sign In OTP – обмен кода и DeviceId на токен (JWT).
  4. (Опционально) Accept OTP если нужен финальный handshake с токеном.
